HOW TO UPDATE YOUR PROJECT
1. Close the running app (Ctrl+C) and COPY your whole "college app" folder as a backup.
2. Unzip this and copy everything into your "college app" folder, replacing files when asked
   (app.py, templates/*, static/style.css, static/notify.js).
3. Do NOT delete the "instance" folder: it holds your database (college3.db).
4. Run: python app.py   (new tables are created automatically, old data stays)
5. Teacher code: change the "1234" in app.py (search TEACHER_CODE).
